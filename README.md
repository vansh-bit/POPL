# ExTetris — Extended Tetris Design and Development

Assignment for **CS F301 Principles of Programming Languages (PoPL), Sem-I, 2026-27**.

## Repository Structure

- `PoPL2026AssignmentExTetris.pdf` — Official assignment specification and Appendix A–D starter code.
- `answers.txt` — Submitted intermediate Moodle quiz responses.
- `AI_INTERACTION_LOG.md` — Chronological, verbatim log of all AI prompts, responses, interpretations, plans, modifications, and outcomes.
- `attempts/` — Preserved runnable snapshots and reports for Attempts 0–4 (`attempts/README.md` maps commits and tags).
- `extetris/` — Final release (**Attempt 5**) modular Python package (`shapes/`, `board/`, `distributions/`, `engine/`, `renderers/`, `config/`, `builder.py`).
- `configs/` — Declarative JSON game variant presets (`classic.json`, `extended.json`, `chaos.json`, `custom.json`).
- `tests/` — Automated test suite organized across 9 categories (unit, configuration, persistence, integration, and packaging).
- `ExTetris_Studio.ipynb` — No-code interactive Jupyter studio for configuring and launching game variants.
- `docs/` — Final documentation suite (`DESIGN.md`, `UML.md`, `API.md`, `GAME_PROGRAMMERS_MANUAL.md`, `AI_USAGE_REPORT.md`).
- `dist/` — Packaged submission output (`extetris_submission.zip`).

## Status

Repository skeleton initialized. Development proceeds progressively from **Attempt 0** (verbatim Appendix A–D baseline) through **Attempt 5** (final verified release).
